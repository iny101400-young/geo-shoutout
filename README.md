# geo-shoutout · 샤라웃 콘텐츠 기획

스폰지클럽 4기 GEO 유닛원들이 같은 조 크루를 소개하는 **샤라웃 콘텐츠**를 기획하는 스킬이에요.

**이 스킬은 글을 대신 쓰지 않아요. 초안도 쓰지 않아요.**
무엇을 어떻게 소개할지 같이 정리해서 보라색 기획 리포트로 드려요.
혼자 쓰기 힘들면 다른 글쓰기 AI 가 **내가 직접 쓰도록 이끌어 주는 프롬프트**를, 직접 쓰고 싶으면 **가이드**를 보고 써요.
글은 내가 쓰고, 검수하고, 올려요.

<br>

## 남이 나를 소개한 글은 AI 가 확인하는 근거가 돼요

AI 는 내 사이트에 적힌 말만 보지 않아요.
**다른 사람이 내 이름 · 하는 일 · 주소를 적어 소개한 글**도 「이 사람이 누구인지」 확인하는 재료로 써요.

- 🔗 **가장 중요한 건 크루의 사이트 주소를 글에 꼭 넣는 것**이에요. 그래야 크루에게 **백링크**(다른 사람 글에서 걸려 온 링크)가 생겨요
- 🚫 크루가 **쓰지 말아 달라고 한 말**은 빼요. 리포트와 체크리스트에서 빨간색으로 보여 드려요
- 링크를 주고받는 게 목적이 아니라, **어떤 독자에게 왜 도움이 되는 곳인지 내 언어로** 소개해요

| 리포트에서 보이는 것 | 예 (가상 크루) |
|---|---|
| 소개할 크루 | 하루 (사이트명 · 하루베이커리) |
| 🔗 꼭 넣을 주소 | https://haru-bakery.example |
| 🚫 쓰지 말아 달라고 한 말 | 「최고의 빵」 · 「무첨가」 |
| 기억에 남은 것 | 재료 원산지를 빵마다 적어 둔 게 눈에 들어왔어요 |
| 내 경험과 이어지는 것 | 우리 아이 간식 고를 때 늘 원산지를 찾아봤어요 |
| 추천 방식 | 2 상황 소개 · 아이 간식을 고르는 부모에게 |

> AI 답은 물을 때마다 달라질 수 있어요. 인용이나 추천을 약속하지는 않아요.

<br>

## 이 스킬로 얻는 것

- **카드 확인부터**  
  활동명만 말하면 유닛 레포에서 내 카드와 소개할 크루 카드를 불러와, 시트와 맞는지 같이 확인해요
- **크루 사이트를 한눈에**  
  어떤 곳인지, 누구에게, 볼 만한 곳, 사이트에 있어도 옮기지 않을 말까지 정리해 드려요
- **쉬운 질문 몇 개**  
  기억에 남은 것과 내 생각을 한 줄씩 적으면 소개 방식 3개를 추천해 드려요
- **보라색 기획 리포트 한 장**  
  나 → 소개할 크루 → 채널별로 어떻게 쓸지 순서로 정리돼요. 크루가 둘이면 카드 · 가이드 · 프롬프트 · 체크리스트가 크루마다 나뉘어요
- **발행 전 체크리스트**  
  작성한 글을 붙여 넣으면 주소 · 이름 · 하는 일 · 쓰지 말 말 · 부풀린 말에서 걸리는 걸 짚어 드려요. 최종 검수는 내가 해요
- **과제 파일에 링크 넣기**  
  발행한 링크를 주면 내 4주차 과제 파일 「발행」 칸에 넣어 드려요

## 이런 분께

스폰지클럽 4기 GEO 유닛원 누구나요. 샤라웃은 4회차 기본 과제예요. **채널 1곳에 올리면 인정**이에요.

## 이렇게 진행돼요

기획까지 10~15분이에요.

1. **활동명**을 알려 주면 내 카드와 크루 카드를 보여 드려요. 시트에 적은 것과 맞는지 확인해요  
   크루 주소가 비어 있으면 여기서 크루에게 확인을 요청해요
2. 크루 사이트를 정리해 드려요. 사이트를 열어 두고 **기억에 남는 것 한 줄**, 그리고 인상 깊었던 것 · 내 경험과 이어지는 것 · 배운 점 중 하나를 골라 **한 줄** 더 적어요
3. 어디에 올릴지 골라요 (한 곳만 골라도 인정). 비슷한 주제의 내 글이 있는지도 물어요
4. 추천하는 소개 방식 3개 중 하나를 골라요
5. 한두 가지만 더 물어요
6. **기획 리포트**가 열려요 → 「프롬프트로 받기」(혼자 쓰기 힘들어요) 또는 「가이드로 받기」(직접 쓸래요)를 보고 **내가 직접 써요**
7. 다 쓴 원본을 「샤라웃 콘텐츠 점검해 줘」와 함께 붙여 넣으면 Claude 가 검수해서 **발행 전 체크리스트**를 열어 드려요 → 고쳐서 **직접 발행**해요
8. 발행한 링크를 「샤라웃 콘텐츠 링크 과제에 넣어 줘」와 함께 주면 4주차 과제 파일 「발행」 칸에 넣어 드려요 → **과제를 다 채우면 커밋 · 푸시**해요

## 기획 리포트

한 장으로 나와요. 브라우저에서 열려요.

| 순서 | 들어 있는 것 |
|---|---|
| 1 · 나 | 내 카드(사이트명 · 하는 일 · 주소 · 내가 피할 말) · 내가 담을 것(기억에 남은 것 · 내 생각 · 이어지는 점) |
| 2 · 소개할 크루 | 크루마다 카드 한 장: 🔗 꼭 넣을 주소 · 🚫 쓰지 말아 달라고 한 말 · 하는 일 · 어떤 곳 · 볼 만한 곳 · 옮기지 않을 말 |
| 3 · 어떻게 쓸까요 | 탭 셋 · 채널마다 정리 (크루가 둘이면 크루마다 나눔) |

| 탭 | 이럴 때 | 들어 있는 것 |
|---|---|---|
| 프롬프트로 받기 | 혼자 쓰기 힘들어요 | 글쓰기 AI 에 붙일 프롬프트. AI 가 질문하고 **내가 한 문단씩** 써요 (크루마다 나눠서) |
| 가이드로 받기 | 직접 쓸래요 | 읽을 사람 · 시작 추천 · 구성 순서 · 말투 · 꼭 넣을 것 · 쓰지 말 것 |
| 🔒 발행 전 체크리스트 | 다 쓴 뒤 | 처음엔 흐리게 잠겨 있어요. 원본을 붙여 넣어 검수받으면 열려요 |

고른 탭이 먼저 열리고, 탭을 눌러 다른 쪽도 볼 수 있어요.

## 소개 방식 5가지

| 방식 | 쉽게 말하면 |
|---|---|
| 1 고객 연결 | 내 글 독자가 궁금해하던 걸 이 크루가 잘 알아요 |
| 2 상황 소개 | 이런 고민이 있을 때 찾아가면 좋은 곳 |
| 3 동료 소개 | 스폰지클럽에서 같이 실험하며 알게 된 크루 |
| 4 큐레이션 | 요즘 알게 된 곳 몇 곳을 묶어 소개 |
| 5 내 글 속 참고 소개 | 내가 쓴 글 안에서 더 알아볼 곳으로 이어 주기 |

## 이런 경우라면

| 이런 경우 | 이렇게 돼요 |
|---|---|
| **소개할 크루가 둘이라면** | 크루 카드 · 🔗 주소 · 가이드 · 프롬프트 · 체크리스트가 크루마다 나뉘어요. 큐레이션(묶어서 소개)을 추천해요 |
| **카드가 다르거나 비어 있다면** | 스킬에서 바로 고쳐 쓸 수 있어요. 시트는 댓글이나 스레드로 남기면 운영진이 시트와 깃허브를 맞춰요. 크루 주소가 비어 있으면 먼저 크루에게 확인을 요청해요 |
| **비슷한 주제의 내 글이 있다면** | 내 글 안에 「더 알아볼 곳」으로 크루를 이어 줘요(백링크) |
| **여러 채널에 올린다면** | 채널마다 순서 · 말투 · 내용을 다르게 짜 드려요. 두 글에 똑같은 문장이 있으면 체크리스트에서 짚어요 |
| **공통 SNS 과제로도 낸다면** | 규칙이 「AI 없이 내 언어로」라서 가이드만 드리고, 해시태그 · 태그 · 인증 체크리스트를 붙여요 |
| **같은 크루를 다른 사람도 소개한다면** | 각도가 겹치지 않게 내가 본 것 중심으로 쓰라고 안내해요 |

## 이 스킬로 안 되는 것

- 글 · 초안을 쓰지 않아요. 프롬프트도 「AI 가 대신 쓰기」가 아니라 「내가 쓰도록 질문하고 이끌기」예요
- 대신 올리거나 로그인하지 않아요
- 시트를 고치지 않아요 (댓글이나 스레드로 남기면 운영진이 맞춰요)
- 레포에서는 내 4주차 파일의 「발행」 칸만 고쳐요. 커밋 · 푸시는 내가 해요
- 카드와 크루의 공개 사이트에 없는 사실 · 숫자 · 후기 · 자격을 만들지 않아요
- 업종 광고 규정은 판단하지 않아요. 「전문가」처럼 조심할 말만 짚어요

## 알아 두면 좋은 것

- 🔗 **크루 사이트 주소는 꼭** 넣어요. 링크 글자는 「여기」 말고 사이트 이름 뒤에 붙여요
- 🚫 크루가 **쓰지 말아 달라고 한 말**은 「~는 아니에요」처럼 부정해도 빼는 게 안전해요
- **크루 사이트명은 카드 표기 그대로** 써요. 띄어쓰기까지요
- **기억에 남은 것 · 내 생각**이 들어가야 진짜 소개로 읽혀요. 카드 내용만 있으면 광고처럼 보여요
- 다른 AI 의 도움을 받았다면 **내 말로 한 번 더** 다듬어요. 내 이름으로 나가는 글이에요
- 공통 SNS 과제로도 낼 거면 스폰지타임즈 규칙(AI 없이 내 언어로 · 해시태그 · 태그 · 4:5 이미지 · 슬랙 인증)을 먼저 따라요
