# 7단계 · 발행 전 체크리스트

판정(통과 · 불통과)이 아니라 「이런 게 걸려요 → 최종 발행 전에 직접 검수해 주세요」다. 고친 문장은 쓰지 않고 자리 · 문장만 짚는다.

| 묶음 | 들어가는 것 |
|---|---|
| **발행 전에 꼭 볼 것** | 크루 이름(카드 표기)이 없음 · 하는 일 한 줄이 카드에 비어 있음 · 대표 주소가 글에 없음 · 카드에 주소가 없음 · 대표 주소가 지금 안 열림(크루에게 확인) · 크루가 피해 달라고 한 낱말 · 남은 빈칸([확인 필요] · (사진: …) · { } · ○○) · 과장 낱말(최고 · 1위 · 넘버원 · 유일 · 최초 · 완벽 · 보장 · 무조건 · 100% · 최대) · 다른 채널 글과 60% 이상 겹침 · (공통 SNS) 해시태그 빠짐 |
| **한 번 더 읽어 볼 것** | 하는 일 한 줄이 글에 보이나(Claude 가 읽고 봄) · 뜻 · 문장으로 적힌 피해 줄 표현(Claude 가 읽고 걸리는 문장 인용) · 내 카드 피해 줄 표현 · 사이트 문장을 그대로 옮긴 곳 · 「전문가」 · 「여기 · 클릭」 링크 글자 · 다른 채널과 40% 이상 겹침 · (공통 SNS) 태그 · 이미지 · 슬랙 인증 · 직접 본 것 · 느낀 것 · 내 말투 |
| **잘 들어갔어요** | 이름 · 주소 등 확인된 것 (크루 확인 전 값이면 그렇다고 적음) |

## 피해 줄 표현 나누기 (check.mjs)
- 괄호 안은 따로 뗀다: 「개인이벤트 기획 (생일파티, 웨딩)」 → 개인이벤트 기획 · 생일파티 · 웨딩
- 끝의 x 표시는 뗀다: 「위탁 판매x」 → 위탁 판매
- 「~말 · ~표현 · ~단정 · ~장담」으로 끝나거나 문장(「~요 · ~다」)이거나 세 낱말 이상이면 **뜻**으로 보고 Claude 가 읽는다: 「효과·결과 장담」 · 「병원처럼 들리는 말」 · 「양말기계를 직접 돌리진 않아요」
- 「A 아니고 B」는 틀린 표기 A 를 찾고 「B 로 써 주세요」라고 알린다: 「모먼트리 아니고 모멘트리」
- 「가 · 나 · 다 같은 ~」은 앞의 낱말(가 · 나 · 다)은 글에서 찾고, 전체는 뜻으로도 본다. 끝의 「금지」는 뗀다
- 「○○님이 쓰신 것과 동일」은 cards.mjs 가 그 크루 카드의 표현을 가져와 붙인다(`avoidFrom` · 크루 확인 권장)
- 「~가 아니에요」처럼 부정문으로 들어간 낱말도 「아예 빼는 게 안전해요」로 알린다
- 내 카드의 피할 말은 크루를 설명하는 문장(크루 이름 · 사이트명이 든 문장)에서는 넘어간다
- 크루가 피해 달라고 한 낱말은 🚫 로 표시하고 리포트에서 빨간색으로 보인다. 크루 주소 관련 줄은 🔗

## 그 밖에 보는 것
- `--plan`: 2단계 「옮기지 않을 말」이 글에 있으면 꼭 볼 것 · 「같이 밝혀 주면 좋은 말」은 한 번 더 볼 것
- `--compare`: 다른 채널 글과 **똑같은 문장**은 꼭 볼 것, 전체가 40% 이상 비슷하면 한 번 더 볼 것(60% 이상은 꼭 볼 것)

## 공통 SNS 과제 체크리스트 (스폰지타임즈 규칙 · 낼 때만)
- [ ] 글은 AI 없이 내 언어로
- [ ] 이미지 4:5 (1080×1350)
- [ ] 해시태그 `#스폰지클럽 #AI커뮤니티 #AI해자`
- [ ] 태그: 인스타 · 스레드는 `@spongeclub.ai`, 링크드인 · 페이스북은 젬마
- [ ] 슬랙 `#공통-sns-기록하고-셸받기` 에 `/SNS 인증`
규칙이 바뀌었을 수 있으니 「스폰지클럽 과제 안내를 한 번 더 봐 주세요」 한 줄을 붙인다.
