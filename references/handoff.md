# 6단계 · 프롬프트로 받기 / 가이드로 받기

**이 스킬도, 다른 AI 도 초안을 대신 쓰지 않는다. 글은 사람이 쓴다.**
리포트(report.mjs) 한 장에 탭 셋으로 나온다. 사용자가 고른 탭이 먼저 열리고, 탭을 바꿔 다른 쪽도 볼 수 있다.

| 탭 | 누구에게 | 들어 있는 것 |
|---|---|---|
| 프롬프트로 받기 | 혼자 쓰기 너무 힘든 사람 | 다른 글쓰기 AI 에 붙여 넣을 「코치 프롬프트」(채널마다 · 복사 버튼) |
| 가이드로 받기 | 직접 쓰고 싶은 사람 | 읽을 사람 · 시작 추천 · 구성 순서 · 말투 · 길이 · 꼭 넣을 것 · 쓰지 말 것 · 링크 글자 |
| 발행 전 체크리스트 | 다 쓴 사람 | 7단계 점검 결과 (점검 전에는 안내만) |

## 코치 프롬프트가 다른 AI 에게 시키는 것
1. 구성 순서대로 한 칸씩, 내가 답하기 쉬운 질문 1~2개 + 어떻게 쓰면 좋을지 추천만 (완성 문장 · 빈칸 문장 틀 금지)
2. 내가 쓴 문장에서 꼭 넣을 것 빠짐 · 쓰지 말 것 들어감만 짚기 (말투는 안 고침)
3. 없는 사실 · 숫자 · 후기 · 자격 금지
4. 다 쓰면 **내가 쓴 문장만** 이어 코드 블록 하나로 (새 문장 추가 금지 · 맞춤법만)
프롬프트 전문은 report.mjs 의 `coachPrompt()` 에 있다. 바꿀 때는 거기만 고친다.

## 공통 SNS 채널
